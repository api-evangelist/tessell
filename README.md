# Tessell

Tessell is a multi-cloud database-as-a-service (DBaaS) platform that runs Oracle, SQL Server, PostgreSQL, MySQL, MongoDB, Milvus, and Apache Kafka inside a customer's own AWS, Azure, or GCP account, under the customer's own encryption keys and network policies. The platform is API-first: everything available in the Tessell console is also available through its REST API (588 operations at https://api.console.tessell.com, documented at https://developer.tessell.com/) and the first-party Terraform provider (tessell-cloud/tessell).

This repository profiles Tessell's API surface for the API Evangelist network — the machine-readable index is [apis.yml](apis.yml), with harvested and derived artifacts under `openapi/`, `authentication/`, `conventions/`, `errors/`, `lifecycle/`, `security/`, `conformance/`, `data-model/`, `mcp/`, `skills/`, `llms/`, `packages/`, `well-known/`, `overlays/`, and `asyncapi/`.
